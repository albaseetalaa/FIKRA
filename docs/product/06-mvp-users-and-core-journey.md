# Fikra AI MVP Users and Core Journey

Status: Approved
Decision date: 2026-07-30
Target release: v1

## Primary v1 User

The primary v1 user is:

A founder or small-business owner in Saudi Arabia or Jordan who has a new idea or an existing business and wants to build a coherent brand, prepare it for launch, and continue marketing it without assembling a full professional team.

The primary experience, onboarding, navigation, recommendations, and product messaging should be designed first around this user.

## Secondary v1 Users

Secondary users include:

- Designers managing projects for clients
- Marketers managing brand and content work
- Consultants supporting small businesses
- Small internal teams collaborating on a project

These users should be supported without allowing agency-specific complexity to dominate the initial product.

Advanced agency management, client portals, external review workflows, and granular team permissions may be introduced after v1.

## Core Customer Problem

The primary customer often has to coordinate several disconnected roles and tools, such as:

- Business strategist
- Market researcher
- Brand consultant
- Designer
- Content writer
- Social media planner
- Website creator
- Packaging or menu specialist

Fikra AI should combine these activities into one coordinated project experience built on shared approved decisions and project memory.

## Flexible Core Journey

The v1 journey follows a shared strategic path:

1. Create the project
2. Understand the idea or existing business
3. Understand the market and audience
4. Approve the strategic foundation
5. Build the brand foundation
6. Produce the first marketing package
7. Prepare the launch plan
8. Continue with recurring content and growth

This journey is guided but not rigid.

Customers must not be required to use every studio.

Fikra AI should activate and recommend studios based on:

- Industry
- Business type
- Project stage
- Existing assets
- Missing decisions
- Customer objectives
- Market context
- Available budget and Fikra Credits

## Adaptive Studio Paths

Examples of adaptive paths include:

### Restaurant or Cafe

Likely studios:

- Logo Studio
- Brand Studio
- Menu Studio
- Packaging Studio
- Social Content Studio
- Basic Website Studio

### E-commerce Store or Product Brand

Likely studios:

- Logo Studio
- Brand Studio
- Packaging Studio
- Social Content Studio
- Basic Website Studio

### Service Business

Likely studios:

- Brand Studio
- Social Content Studio
- Basic Website Studio

Studios remain accessible when appropriate, but Fikra AI should recommend only what meaningfully advances the project.

## First-Session Outcome

The first session should not attempt to complete an entire brand.

A successful first session should help the customer:

- Create the project
- Provide or import the essential context
- Understand the project's current state
- Approve at least one meaningful decision
- Receive at least one useful output
- See no more than three recommended next actions

Useful first-session outputs may include:

- Project summary
- Target-audience definition
- Value proposition
- Initial brand direction
- Market-positioning proposal
- Prioritized next-step plan

The customer should leave the first session feeling that Fikra AI understands the project and has created meaningful forward progress.

## Initial Industry Templates

The first v1 industry templates should be:

1. Restaurant or cafe
2. E-commerce store or product brand
3. Service business

These templates were selected because they cover meaningfully different needs while collectively exercising most approved v1 studios.

The initial release should prioritize a small number of strong templates rather than many shallow templates.

Additional templates may be introduced later for:

- Personal brands
- Technology companies
- Real-estate projects
- Salons
- Clinics
- Other market-specific industries

## Template Behavior

An industry template may influence:

- Onboarding questions
- Recommended agents
- Recommended studios
- Expected project artifacts
- Industry terminology
- Common risks
- Suggested project order
- Market-specific examples

Templates must remain editable.

A template must not force unverified assumptions into approved project memory.

## v1 Roles

The initial product roles are:

### Owner

Can:

- Manage the project
- Make final approvals
- Manage members
- Manage billing and Fikra Credits
- Change project settings
- Delete or export the project

### Editor

Can:

- Create and edit project content
- Run approved workflows
- Produce drafts and artifacts
- Propose project-memory updates
- Prepare items for approval

An Editor cannot silently replace high-impact approved decisions unless explicitly authorized.

### Viewer

Can:

- View permitted project information
- View approved artifacts
- Review project progress

A Viewer cannot modify project content or approve decisions.

## Deferred Collaboration Features

The following are not required for the first v1 release:

- External Reviewer role
- Public client review links
- Advanced agency workspaces
- Custom permission builders
- Department-level permissions
- Complex approval chains
- Multi-organization administration

The technical design should avoid preventing these capabilities from being added later.

## Success Signals

The v1 experience should measure whether customers:

- Complete project creation
- Complete the essential onboarding context
- Approve a first meaningful decision
- Produce a useful first output
- Use approved memory across more than one studio
- Return to continue the project
- Return for recurring Social Content Studio use
- Understand expected Fikra Credit consumption
- Complete workflows without requiring human support
- Avoid contradictions between outputs from different studios

Final numerical targets will be defined after observing real customer usage and establishing a reliable baseline.

## MVP Focus Principle

Fikra AI v1 should deliver one coherent, high-value journey exceptionally well before expanding into many specialized user types.

The core strategy, brand, launch, and growth journey is shared.

Execution studios are activated flexibly according to the needs of each project.

The customer should experience Fikra AI as a coordinated digital team that understands what the project needs next, not as a checklist requiring every available tool.
